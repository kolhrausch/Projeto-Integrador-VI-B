# APK do aplicativo

O arquivo **`vitrine.apk`** desta pasta é gerado automaticamente pelo GitHub Actions
(workflow [Build APK](../.github/workflows/build-apk.yml)) a cada alteração no código.

Para instalar no celular Android: baixe `vitrine.apk`, abra o arquivo e permita a
instalação de apps de fontes desconhecidas quando o Android pedir.

Para gerar manualmente, veja [docs/06-geracao-apk.md](../docs/06-geracao-apk.md).
